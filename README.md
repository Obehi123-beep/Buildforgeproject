# BuildForge 

BuildForge is a responsive construction and architecture business website built with HTML, CSS, and JavaScript. The project features a multi-page layout showcasing industrial construction services, architectural designs, team profiles, project insights, and client consultation forms.

## Technologies Used
* **HTML5** - Semantic layout and multi-page structure
* **CSS3** - Custom styling, responsive grid layouts, and visual components
* **JavaScript** - Dynamic UI interactions and navigation

## Features & Highlights
* **Service Showcase**: Dedicated pages for architectural design, interior design, equipment, and mechanical engineering services
* **Multi-Page Architecture**: About Us, Team Details, Services, FAQ, Testimonials, and Blog sections
* **Interactive Contact & FAQ**: Simple inquiry form and collapsible FAQ section for potential clients
* **Responsive Layout**: Designed for seamless browsing across mobile, tablet, and desktop viewports
